# My Theme Booking - Custom WordPress Theme

A custom WordPress theme built with Sage (Roots), Tailwind CSS, and Vite, implementing a Figma design for a luxury villa rental.

## 📸 Screenshots

![Hero Section](screenshot.png)

*Hero section with background image, headline, and CTA buttons.*

## ✨ Features

- **Sage (Roots) architecture** with Laravel Blade templating
- **Tailwind CSS** for utility-first, responsive styling
- **Vite** for fast build and hot-reloading
- **Custom header** with scroll-based animation (transparent to solid)
- **Hero section** with gradient overlay and responsive text
- **Figma to code** workflow: design implemented from a Figma template

## 🛠️ Tech Stack

| Tech | Purpose |
| :--- | :--- |
| WordPress | CMS |
| Sage (Roots) | Theme starter |
| Laravel Blade | Templating |
| Tailwind CSS | Styling |
| Vite | Build tool |
| Composer | PHP dependencies |
| Yarn | JS dependencies |
